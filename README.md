# 🚐 Camper Rental App

This is a web application for browsing, filtering, and booking camper vans. Built with React, Redux Toolkit, modular CSS, and routing. The project uses data from MockAPI and follows a component-based architecture.

## 📦 Technologies Used

- React + Vite
- Redux Toolkit
- React Router
- React Hot Toast (notifications)
- CSS Modules
- SVG Icons
- LocalStorage (favorites)
- React Lazy Loading + Suspense
- MockAPI (as backend)

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/voxa-ace/rent-TravelTrucks-app.git

### 2. Install dependencies
npm install

### 3. Start development server
npm run dev

4. Open in your browser
http://localhost:5173


Features
Camper listing with image, description, rating, location, and equipment

Filtering by location, equipment (AC, kitchen, etc.), and vehicle type

Detail page with full description, gallery, features, reviews

“Add to Favorites” feature with persistence via LocalStorage

Booking form with validation and success notification

Lazy loaded pages using React.lazy() and Suspense

404 page for invalid routes
